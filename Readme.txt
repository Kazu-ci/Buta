ゲーム概要
このゲームは豚をはじいて転がしてぶっ飛ばすゲームです。
2人対戦用のゲームで持ち球を落とし合いスコアが高かった方が価値のゲームです

ゲームの操作

・ゲーム開始時にAボタン→プレイヤーのエントリー

・インゲーム中にAボタン→スコアを2消費しリスポーン

・左スティック→プレイヤーの移動

・右トリガー押しこみ→チャージ

・右トリガーを離す→ぶっ飛ばす

・Esc→ゲーム終了

・各操作→マウス

ゲームの流れ
		　　　→トランポリンステージ
タイトル→ステージ選択→ノーマルステージ　　　→リザルト→タイトルへ
		　　　→アイスステージ

ゲームの特徴

このゲームは跳ねて転がるをコンセプトに作りました。
壁、相手プレイヤーにぶつかると気持ちよく跳ねます。
素直な直観的な操作ではなく、物理挙動を制御するような操作感にしました。
またプレイヤーに長く遊んでもらうためにノーマルステージのほか2つのステージを用意しました。（normal以外は時間が無くできませんでした）
このステージでは慣性が働きすぎたり、反射しすぎたりと現実ではありえない物理挙動をします。

チャージの際UIバーをつけ分かりやすくしました。

シーン遷移の際の画面演出（フェードイン、フェードアウトなど）

リザルトのオブジェクトの動きをこだわりました。

マップギミックで隕石を落としプレイヤーが死ぬため、リスポーンが必要になるので駆け引きを生むようにしました。
